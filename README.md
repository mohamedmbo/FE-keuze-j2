# Front-end keuzevak – opdrachten 1 en 2

Deze repository bevat de eerste twee opdrachten van het front-end keuzevak.

## Opdracht 1 – React

De map `opdracht-1-react` bevat een responsive React-website met:

- herbruikbare React-componenten;
- een eigen 12-koloms CSS Grid-systeem;
- een carousel en responsive navigatie;
- wireframes voor desktop en mobiel.

## Opdracht 2 – Vue

De map `opdracht-2-vue` bevat een responsive Vue-website met:

- herbruikbare Vue-componenten;
- Bootstrap als basis voor de responsive layout;
- een carousel en filterbare projecten;
- wireframes voor desktop en mobiel.

## Project starten

Open de gewenste opdrachtmap en voer uit:

```bash
npm install
npm run dev
```
